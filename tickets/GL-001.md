## B) Test Scenarios (UI→API→DB)

### B.1) Retailer POS Flow Test

#### Test Steps:
1. **Install POS on fresh device**
   - Device has no store binding
   - See onboarding wizard (not enrollment code entry)

2. **Complete Step 1 - Store Details**
   - Enter: Store name, address, type, GSTIN, owner info, phone (OTP)
   - Verify: OTP received and works
   - Proceed to Step 2

3. **Complete Step 2 - Documents**
   - Upload: Aadhaar (camera), GST certificate (gallery), Owner selfie
   - Verify: Uploads complete without error

4. **Complete Step 3 - Payments**
   - Enter: UPI address
   - Optional: Bank details
   - Submit

5. **Verify LIMITED MODE**
   - See: "Pending approval" message
   - Navigate to SELL → See locked overlay
   - Navigate to Products → Can create products
   - Try API: `POST /sales` → 403

6. **Admin Approval**
   - Go to SuperAdmin
   - Find store in pending queue
   - Review application
   - Click Approve

7. **SELL Unlocked**
   - POS refreshes or polls
   - LIMITED MODE banner gone
   - SELL screen now works
   - Can create sale, process payment

### B.2) Retailer Web Flow Test

#### Test Steps:
1. **Register store on web**
   - Go to `/register`
   - Complete wizard (Details → Documents → Payments)
   - Verify: Store created in DRAFT status

2. **Generate activation code on POS**
   - Fresh POS device shows activation code
   - Code format: SM-XXXX-XX
   - Timer counting down

3. **Enter code on web**
   - Go to Devices → Add Device
   - Enter activation code
   - Verify: Device bound, store → ENROLLED

4. **Complete KYC on web**
   - Upload documents if not done
   - Verify: Status → KYC_SUBMITTED

5. **Complete payments on web**
   - Enter UPI address
   - Verify: Status → PAYMENTS_SUBMITTED

6. **Admin approval**
   - SuperAdmin approves
   - Verify: Status → ACTIVE

7. **POS now functional**
   - POS detects binding
   - Can access all features

### B.3) Supplier Flow Test

#### Test Steps:
1. **Register with OTP**
   - Go to supplier portal `/register`
   - Enter phone → OTP
   - Enter business details
   - Submit

2. **See pending status**
   - Redirected to pending-approval page
   - Cannot access dashboard

3. **Upload documents**
   - Upload GST, PAN, bank statement
   - Verify: Uploads complete

4. **Admin reviews**
   - SuperAdmin sees supplier in queue
   - Reviews KYC
   - Clicks Verify

5. **Portal unlocked**
   - Supplier refreshes
   - Dashboard now accessible
   - Can add products, view orders
