  - Updates verified flag

- [ ] **KYC-001-API-REQUEST**: `POST /api/v1/admin/documents/:id/request-reupload`

### B.3) DB/Migration Subtickets

#### B.3.1) Schema Changes
- [ ] **KYC-001-DB-STORE**: `platform.store_documents` table
  - Migration: `072_store_documents.sql` (from RET-POS-001)
  - Already defined — verify columns

- [ ] **KYC-001-DB-SUPPLIER**: `supplier.supplier_documents` table
  - Migration: `074_supplier_documents.sql`
  ```sql
  CREATE TABLE IF NOT EXISTS supplier.supplier_documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_id UUID NOT NULL REFERENCES supplier.suppliers(id),
    document_type VARCHAR(50) NOT NULL,
    file_url TEXT NOT NULL,
    uploaded_at TIMESTAMPTZ DEFAULT NOW(),
    verified BOOLEAN DEFAULT FALSE,
    verified_at TIMESTAMPTZ,
    verified_by UUID,
    needs_reupload BOOLEAN DEFAULT FALSE,
    reupload_reason TEXT
  );
  CREATE INDEX idx_supplier_documents_supplier ON supplier.supplier_documents(supplier_id);
  ```

## D) Verification Proof (must be attached per ticket)

### D.1) Curl Proof

```bash
# Upload store document
curl -X POST https://supermandi.tech/api/v1/stores/STORE_ID/documents \
  -H "Authorization: Bearer TOKEN" \
  -F "document_type=aadhaar" \
  -F "file=@/path/to/aadhaar.jpg"
# Expected: 201 { "id": "uuid", "document_type": "aadhaar", "file_url": "https://...", "verified": false }

# List store documents
curl -X GET https://supermandi.tech/api/v1/stores/STORE_ID/documents \
  -H "Authorization: Bearer TOKEN"
# Expected: 200 [{ "id": "...", "document_type": "aadhaar", "verified": false }, ...]

# Admin verify document
curl -X PATCH https://supermandi.tech/api/v1/admin/documents/DOC_ID/verify \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "verify"}'
# Expected: 200 { "id": "...", "verified": true }

# Admin reject document
curl -X PATCH https://supermandi.tech/api/v1/admin/documents/DOC_ID/verify \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "reject", "reason": "Image is blurry"}'
# Expected: 200 { "id": "...", "verified": false, "needs_reupload": true, "reupload_reason": "Image is blurry" }

# Try to activate store with missing docs (should fail)
curl -X PATCH https://supermandi.tech/api/v1/admin/stores/STORE_ID/status \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"status": "ACTIVE"}'
# Expected: 400 { "error": "Missing required documents: gst_certificate, owner_selfie" }
```
