## Defense-in-Depth Layers

1. **SuperAdmin UI**: Checkboxes — controls which methods a store can use
2. **Admin PATCH API**: Validates CASH/UPI/DUE only, non-empty array
3. **POS ui-status**: Returns allowed methods → POS hides disabled tabs
4. **Sale confirm**: Backend 403 `payment_method_not_allowed` (inside txn, first check)
5. **Split payment**: Backend 403 `payment_method_not_allowed` (per split component)
